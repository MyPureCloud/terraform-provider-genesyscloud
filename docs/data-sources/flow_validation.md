# genesyscloud_flow_validation (Data Source)

<!-- This document is automatically generated. Do not edit manually. Make changes to the schema, examples, or apis.md files in examples/data-sources/ and run 'make docs' to regenerate. -->

Validates an existing Genesys Cloud Architect flow by running a validate job (POST /api/v2/flows/validate/jobs) and waiting for it to finish.

Select the flow by `flow_id`, or by `name` and `type`. Validation runs every time the data source is read. Set `fail_on_error` to make the plan or apply fail when the flow has validation errors.

In addition to the permissions listed below, the OAuth client needs `architect:jobValidate:create` to register the validate job.

## API Usage

The following Genesys Cloud APIs are used by this data source. Ensure your OAuth Client has been granted the necessary scopes and permissions to perform these operations:

* [GET /api/v2/flows/validate/jobs/{jobId}](https://developer.genesys.cloud/devapps/api-explorer#get-api-v2-flows-validate-jobs--jobId-)

## Permissions and Scopes

The following permissions are required to use this resource:

* `architect:jobValidate:view`

The following OAuth scopes are required to use this resource:

* `architect`
* `architect:readonly`


## Example Usage

```terraform
# Validate a flow by ID and fail the plan if it has errors
data "genesyscloud_flow_validation" "inbound" {
  flow_id       = genesyscloud_flow.inbound_call_flow.id
  fail_on_error = true
}

# Validate a specific version of a flow selected by name and type, and report the results without failing
data "genesyscloud_flow_validation" "inqueue" {
  name    = "Default In-Queue Flow"
  type    = "inqueuecall"
  version = "1.0"
}

output "inqueue_flow_valid" {
  value = data.genesyscloud_flow_validation.inqueue.valid
}

output "inqueue_flow_errors" {
  value = data.genesyscloud_flow_validation.inqueue.errors
}
```
