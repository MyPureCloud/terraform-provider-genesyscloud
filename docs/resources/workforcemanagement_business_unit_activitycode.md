## Schema

### Required

- `business_unit_id` (String) The id of the business unit this activity code belongs to. Changing this attribute will cause the activity code to be dropped and recreated.
- `category` (String) The category of the activity code (for example OnQueueWork, Break, Meal, Meeting, OffQueueWork, TimeOff, Training, Unavailable or Unscheduled). Attempting to change the category of a default activity code will return an error.
- `name` (String) The name of the activity code.

### Optional

- `agent_time_off_selectable` (Boolean) Whether an agent can select this activity code when creating or editing a time off request. Only applicable when the category is TimeOff.
- `counts_as_paid_time` (Boolean) Whether an agent is paid while performing this activity. Defaults to `false`.
- `counts_as_work_time` (Boolean) Whether the activity should be counted as contiguous work time for calculating daily constraints. Defaults to `false`.
- `counts_toward_shrinkage` (Boolean) Whether this activity code counts toward shrinkage calculations. Defaults to `false`.
- `interruptible` (Boolean) Whether this activity code is considered interruptible. Defaults to `false`.
- `length_in_minutes` (Number) The default length of the activity in minutes.
- `planned_shrinkage` (Boolean) Whether this activity code is considered planned (true) or unplanned (false) shrinkage. Defaults to `false`.
- `secondary_presence_ids` (Set of String) The ids of the secondary presences of this activity code.

### Read-Only

- `default_code` (Boolean) Whether this is a default activity code. Default activity codes are created by Genesys Cloud and cannot be deleted.
- `id` (String) The ID of this resource.
